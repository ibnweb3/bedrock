How it works

From a pasted list to a decision you control

  1. Paste your references

    Any text that contains DOIs works, up to 300 at a time. Bedrock finds them and ignores the rest.

  2. The graph finds the paths

    FalkorDB follows citations up to two hops and returns every path that reaches a retracted work, with the retraction date and the recorded reasons. 150 references take about 0.05 seconds.

  3. The agent explains, you decide

    A language model summarizes the findings and proposes edits. It can only read. Nothing changes until you approve each action.

    Built to be checked

    The agent is on a short leash

    It can read, never write

    The agent has three tools, all read-only. None of them changes a bibliography. Edits happen only when you approve them on the page, and the server applies only the actions it proposed itself.

    Every DOI is checked against the data

    After the agent answers, each DOI it mentions is compared with what the tools returned. An invented or mistyped one shows up as a warning.

    The findings do not depend on the model

    The finding cards come straight from graph queries. If the model is slow, rate-limited or wrong, you still get the full audit.

    It never accuses people

    Findings concern papers and citation paths. The public demo holds no author data. A flag is a prompt for human review.

    What we tested

    We tried to predict retractions. It did not work, so Bedrock does not claim to.

    Before looking at any result, we wrote down the success test: a graph method had to beat the best simple baseline, and the gap had to survive removing the largest journal. We then ran it on 134,798 articles with 140 later retractions.

    The result: no reliable improvement. The best combination beat the journal baseline by a margin well inside the uncertainty, the multi-hop signals did not beat their one-hop versions, and most of the 140 retractions came from a handful of journals. One signal did stand out: a paper that cites an already retracted work was 5 to 12 times more likely than average to be retracted later, depending on the cutoff. That is a lookup, so Bedrock reports exact provenance instead of forecasts. Method, intervals and caveats are in docs/RESULTS.md.
